# 🤖 Classificação de Score de Crédito com Machine Learning | Credit Risk Analytics

## 📌 Visão Geral
Este projeto apresenta uma **análise de dados completa aliada à construção de um modelo de Machine Learning**, utilizando **Python, Pandas e Scikit-learn**, com o objetivo de **prever automaticamente o score de crédito de clientes**.

A solução analisa o perfil financeiro e comportamental dos clientes e classifica o **score de crédito em três categorias**:
- **Poor**
- **Standard**
- **Good**

O projeto simula um **cenário real de risco de crédito**, muito comum em instituições financeiras, fintechs e áreas de crédito, demonstrando a aplicação prática de **Data Analytics, Machine Learning e tomada de decisão orientada a dados**.

---

## 🎯 Objetivo do Projeto
- Analisar dados de clientes e identificar padrões relevantes
- Preparar e tratar dados para uso em modelos de Machine Learning
- Construir modelos preditivos de classificação
- Avaliar o desempenho dos modelos
- Prever o score de crédito de novos clientes automaticamente
- Demonstrar habilidades práticas em **Análise de Dados, BI e Ciência de Dados**

---

## ▶ Demonstração do Processo Analítico
1. Importação e exploração inicial da base de clientes  
2. Limpeza e preparação dos dados  
3. Transformação de variáveis categóricas em numéricas  
4. Separação dos dados em treino e teste  
5. Criação e treinamento de modelos de Machine Learning  
6. Avaliação da performance dos modelos  
7. Escolha do melhor modelo  
8. Aplicação do modelo em novos clientes  

---

## 🧠 Descrição da Análise e Modelagem
O projeto envolve as seguintes etapas técnicas:

- **Análise Exploratória de Dados (EDA)** para entendimento do perfil dos clientes
- Tratamento de valores nulos e inconsistentes
- Codificação de variáveis categóricas utilizando **LabelEncoder**
- Separação entre variáveis explicativas (X) e variável alvo (y)
- Divisão da base em **dados de treino e teste**
- Construção de modelos de classificação supervisionada
- Comparação de performance entre diferentes algoritmos

---

## 🧪 Modelos de Machine Learning Utilizados
- **Random Forest Classifier**
- **K-Nearest Neighbors (KNN)**

Os modelos foram avaliados utilizando métricas de **acurácia**, permitindo a escolha do modelo com melhor desempenho para o problema proposto.
